# Couch Kapew

Two-player local (sharing keyboard) PVP 2D top down shooter.

Draw your player. Record your sound. Fight!

## Controls
Player 1
Move: WASD
Fire: Space

Player 2
Move: OKL;
Fire: N

## Run Locally
### Initial installation - run once
```
npm install -g http-server
```

### Run
```
http-server --watch
```

If using Firefox on windows, `Ctrl+Shift+R` to hard refresh.
